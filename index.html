Laboratoire de sécurité réseau · Avril 2026
▸

Déploiement d'une authentification 802.1X sur infrastructure virtualisée à trois machines, remplaçant un mot de passe Wi-Fi partagé par une identification individuelle via un serveur RADIUS, avec supervision centralisée des connexions.

AUDIT — 11 FAILLES IDENTIFIÉES

Audit de sécurité PostgreSQL — Projet UK 2026

Audit & cloisonnement des privilèges · Juillet 2026
▸

Audit de deux applications NestJS/TypeORM partageant une même base PostgreSQL via un compte superutilisateur unique. Remplacement par deux comptes dédiés à privilèges cloisonnés, et identification des failles de contrôle d'accès dans le code des deux applications.

  • Failles trouvées11 vulnérabilités : contrôles de rôle absents ou inversés, secret JWT codé en dur, mots de passe stockés en clair, port PostgreSQL exposé, schéma non figé
  • CloisonnementMatrice de droits par table selon le principe du moindre privilège, aucun compte SUPERUSER
  • Défense en profondeurLes GRANT PostgreSQL bloquent l'exploitation des failles applicatives même non corrigées côté code
  • TestsScript automatisé de vérification des privilèges — 10/10 tests réussis sur environnement Docker réel
